## 폐병원 스테이지 맵 요약

- 테마: 폐병원, 수술실, 어두운 복도
- 진행: `시작 -> 초반 전투 -> 갈림길 -> 숨겨진 보상 -> 함정 -> 미니보스 -> 회복 지점 -> 최종보스`
- 형식: 좌표 기반

### 핵심 설계 의도

- 초반은 짧은 바닥과 약한 적 2마리로 조작 적응 구간입니다.
- `x=980~1680` 구간은 상단 메인 루트와 하단 숨겨진 루트로 분기됩니다.
- 숨겨진 길은 `갈라진 바닥 아래`로 떨어져 진입합니다.
- 위험 구간은 전기 바닥, 낙하 틈, 점프 플랫폼으로 구성했습니다.
- 위험 구간을 넘으면 반드시 보상 방이 나오도록 배치했습니다.
- 미니보스는 전체 길이의 약 70% 지점인 `x=3720` 근처에 배치했습니다.
- 최종보스 방은 넓고 단순한 수술실 구조로 만들었습니다.

### 현재 데이터에 들어 있는 것

- 플랫폼 좌표
- 적 배치
- 함정 좌표
- 보상 좌표
- 숨겨진 길 진입/이탈 정보
- 체크포인트
- 보스 구역 범위

### 바로 게임에 연결할 때 쓰는 순서

1. `platforms`를 현재 게임의 발판 배열로 연결
2. `enemies`를 잡몹/보스 스폰 데이터로 연결
3. `hazards`를 데미지 판정과 시각 효과로 연결
4. `rewards`를 아이템 오브젝트로 연결
5. `zoneFlow`를 대사/배경 전환 기준으로 사용
